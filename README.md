# PeekMemo

PeekMemo는 화면 가장자리에 숨겨두고 필요할 때만 펼쳐서 사용하는 Windows용 플로팅 메모 프로그램입니다.

작업 중 빠르게 메모를 확인하고 기록할 수 있도록 설계되었으며, 화면 공간을 최소한으로 차지합니다.

## 주요 기능

* 화면 좌측/우측 가장자리에 메모 숨김
* 마우스오버 또는 클릭으로 메모 열기
* ESC로 메모 접기
* 메모 자동 저장
* 인덱스 최대 3개 지원
* 인덱스별 제목/색상 설정
* Ctrl+Shift+1~3 전역 단축키 지원
* 현재 메모 내 검색 기능
* 트레이 아이콘 지원
* 작업표시줄 숨김
* Windows 시작 시 자동 실행
* 저장 위치 변경 지원
* OneDrive 폴더 저장 지원
* 다중 모니터 지원
* 인덱스 삭제 시 백업 보관

## 단축키

| 단축키          | 기능              |
| ------------ | --------------- |
| Ctrl+Shift+1 | 1번 인덱스 메모 열기    |
| Ctrl+Shift+2 | 2번 인덱스 메모 열기    |
| Ctrl+Shift+3 | 3번 인덱스 메모 열기    |
| Ctrl+F       | 현재 메모에서 검색      |
| ESC          | 검색창 닫기 또는 메모 접기 |

## 저장 위치

기본 저장 위치는 사용자 AppData 폴더입니다.

설정에서 저장 위치를 변경할 수 있으며, OneDrive 폴더를 선택하면 메모 파일을 OneDrive에 저장할 수 있습니다.

## 저장 방식

메모 내용은 자동 저장되며 프로그램 재실행 후에도 유지됩니다.

삭제된 인덱스는 백업 폴더로 이동되어 복구가 가능합니다.

## 트레이 아이콘

PeekMemo는 작업표시줄에 표시되지 않고 트레이 아이콘으로 실행됩니다.

트레이 아이콘에서 다음 기능을 사용할 수 있습니다.

* 열기
* 종료
